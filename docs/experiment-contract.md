# Experiment contract

The imported package is v0.3.0 / plan schema 3. Core bytes and original tests are
unchanged. Schema-2/v0.2 results require their original harness. Do not silently
convert, merge or regrade old experiments.

## Treatments and maintenance

A uses basic instructions; B directly includes design principles; C provides the
identical body as an optional design-check Skill. C availability is not forced use.
Track actual loading separately; do not select users after observing outcomes.

Freeze T0, then start independent local-change and extension branches from that
same snapshot in fresh neutral sessions. Do not pass builder chat, experimental
Skill or the other branch. The opt-in actual-T0-disk contract restores the same
archive independently for both branches. It covers bounded regular-file state,
not database concurrency or power loss.

## Outcomes and provenance

Grade externally; responses cannot self-certify success. Preserve artifacts,
attempts, receipts, seeds and suite fingerprints. In the imported protocol a
non-completed agent stage cannot become a regular successful score. Cutoff
diagnostics are separate; artifact-first grading requires a new prospective protocol.

Report functionality, completion, infrastructure, upgrades and known use separately.
Unknown use stays null; cached input is a subset of input. Adaptive recoveries are
not independent initial samples. Do not invoke passed phases again.

## Execution and resource boundaries

Candidates require offline Docker with minimal mounts, non-root user, read-only
root, dropped capabilities and per-process limits. No credentials, evaluator files
or Docker socket may be exposed; no host fallback. Docker mitigates risk but does
not prove isolation against arbitrary malicious programs. Only trusted bundled
reference fixtures may run on the host.

resource-policy.json applies prospectively: local total/stage Token, agent time and
tool-call caps are null. Stop on quota/auth errors, back off on transient 529, retain
per-process test limits. The historical planner rejects null budgets and old live
interfaces remain bounded. Until the runner PR, this baseline supports review and
reproduction, not a compliant launcher for new paid experiments.

## Interpretation

Pair conditions within family/language/repetition. Correlated language ports are
not independent families. Report strata, not raw cross-language runtime rankings.
Levels are designed categories, not calibrated labels. Public tasks and one
provider-declared model do not establish general capability or Skill benefit.
