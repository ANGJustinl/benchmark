## 使用与边界

```bash
source /workspace/changebench-validation/activate.sh
cd /workspace/changebench-repair
python -m pytest -q
CB_REPAIR_IMAGES=/workspace/changebench-repair-results/images.json \
  CB_REPAIR_RESULTS=/tmp/cb-docker-new python -m pytest -q integration
```

详细参数及新契约见源码 `docs/REPAIRS.zh-CN.md`。计划 schema 为 3，旧计划使用原版工具审查，不转换、不覆盖旧成绩。SHA256 清单检测文件改动，不是数字签名。

本次完成工程修复和运行验证。原预算及 60k 示例仍未校准；Token 上限仍是收到收据后执行的阶段终止规则，不能保证严格计费封顶。修复后的 Codex 适配器经过无网络模拟测试，尚未重新做真实付费传输验收；下一轮应先验收客户端，再用预先定义的规则校准预算和新的留出任务。当前结果不能建立模型/Skill 排名。

持久升级门禁限普通文件/目录和明确的状态大小/数量，不覆盖并发、断电一致性或任意文件系统元数据语义。执行计时仍含握手后 Docker 客户端结束延迟；容器检查不是对抗性隔离认证。CI 文件已配置，本地等价命令已运行，尚未在 GitHub Actions 上执行。
